# AttnForge · 注意力锻造炉

> 纯 JavaScript 手写 **Scaled Dot-Product Self-Attention**，零框架、零依赖、单文件。
> 浏览器里拆解 Transformer 的注意力机制：缩放点积、因果掩码、多头、正弦位置编码，外加一个**免反向传播的数值学习演示**——注意力自己学会「软 argmax」。

## 核心算法

| 模块 | 说明 |
|------|------|
| **缩放点积注意力** | `softmax(Q·Kᵀ / √dₖ)·V`，手写独立朴素三重循环参照实现 |
| **因果掩码** | 上三角置 −∞，解码器自回归，行 0 one-hot |
| **多头注意力** | 分头投影 → 各头 softmax → 拼接 → 输出投影 `Wᵒ` |
| **正弦位置编码** | `PE(pos,2i)=sin(pos/10000^(2i/d))`，相对位置内积只依赖 k |
| **软 argmax 学习** | 注意力权重学会把质量集中到「键最大」的 token（解析梯度 + 梯度检验） |

## 招牌不变量（无头 8/8 全绿）

引擎逻辑与验证逻辑**互相独立重算**，一条不变量都不过就是真 bug：

1. **注意力权重行和 == 1**，被掩码位置严格为 0
2. **缩放点积 == 朴素三重循环**（独立实现，Δ < 1e-12）
3. **Softmax 平移不变**：+1e3 严格不变（Δ 1.6e-14）；+1e6 量级不 NaN（减法本身精度损失 1e-11，已分离断言）
4. **因果掩码**：上三角全 0、行和仍为 1、首行 one-hot
5. **置换等变性**（无掩码）：打乱 token 顺序 → 输出行同步置换
6. **多头拼接投影 == 各头分块投影之和**（Δ = 0）
7. **位置编码**：逐元素吻合公式 + 相对位置内积只依赖位移 k
8. **注意力反向传播**：解析梯度 == 中心差分（**maxRelErr = 5.86e-7**）＋软 argmax 留出集命中 **84.3%**、损失 0.4308 → 0.00010

## 硬核发现

- **参照实现漏掩码被测试抓死**：朴素三重循环一开始忘了加 `mask`，案例 2（有因果掩码）直接 Δ 爆掉 —— 独立重算的价值。
- **Softmax 平移是减法精度损失，不是 bug**：+1e6 量级下 `max - x` 浮点减法引入 ~1e-11 误差，与数学无关；+1e3 仍精确到 1e-14。
- **数值梯度太慢**：中心差分 400 步要 ~10 秒只到 73%。正解是写注意力解析反向传播，梯度检验 5.86e-7 验死后，3000 步 2.4 秒收敛到 84.3%。
- **学到的 key 方向对齐 e₀**：`m = Wᵏq ≈ [81.6, −8.6, −5.3, …]`，注意力自然把最大权压在键最大的 token。

## 交互功能

- Q / K / V 矩阵实时编辑，注意力热区 + 加权输出并排
- 因果掩码开关：看解码器自回归如何屏蔽未来
- 多头可视化：各头发散度（mean pairwise distance），验证头不坍缩
- 位置编码几何：范数恒定 ≈ 2.0、相对位置内积曲线
- 软 argmax 训练动画：损失曲线 + 留出集命中权重实时跳动
